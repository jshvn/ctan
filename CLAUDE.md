# ctan -- Project Instructions for AI Agents

## What This Is

A daily-synced mirror of `CTAN/systems/texlive/tlnet` on Cloudflare R2, orchestrated by
`Taskfile.yml` and run by `.github/workflows/sync.yml`. Read `HANDOFF.md` for current state
and `docs/SPIKE.md` for the measurements behind every number here.

## Hard Constraints

- Zero running cost. Every change must stay inside the R2 free tier (10 GB-month storage,
  1M Class A, 10M Class B) and free GitHub Actions. If a change adds storage, recompute
  against the 6.8 GB baseline before proposing it.
- No shell scripts. All logic lives in `Taskfile.yml`; the workflow installs tools and runs
  `task sync`, nothing more. No Python, no `.sh` files.
- No new dependencies beyond `rsync`, `rclone`, `gpg`, `shasum`, `task`.
- No AI attribution anywhere (no Co-Authored-By trailers, no "generated by"). No emojis.

## Gotchas

- `tlmgr` over HTTP requests the unversioned name `archive/foo.tar.xz`. Upstream stores
  `foo.r123.tar.xz` and symlinks the unversioned name to it. R2 has no symlinks, so `fetch`
  uses `rsync -L` and excludes `*.r[0-9]*.tar.xz`. Never store both forms: that doubles
  storage to 13.4 GB and breaks the free tier.
- Files are overwritten in place on revision bumps, so `rclone` must run with `--checksum`.
  Size-only comparison misses same-size updates (`texlive.tlpdb.sha512` is always the same
  length).
- `publish` order is load-bearing: `archive/` first, then the full `sync`. A client must never
  read a `texlive.tlpdb` that names a container the bucket lacks.
- `verify` pins the TeX Live primary key fingerprint. The keyring is fetched from the mirror
  being verified, so the pin is the only thing that distinguishes upstream from an attacker.
  Rotate it only against https://www.tug.org/texlive/verify.html.
- Keep uploads single-part (`--s3-upload-cutoff` above the largest file, currently 145 MB).
  Multipart costs three or more Class A ops per file.
- `.xz` is not in Cloudflare's default cache list, so there is no stale-edge problem. If a
  cache-everything rule is ever added, add a purge-everything step to `publish`.
- Public repos have scheduled workflows disabled after 60 days without a commit.

## Verifying a Change

- `task --dry sync` renders the pipeline without touching the network.
- `task size` is the live upstream dry run (file count and bytes; must stay under 10 GB).
- `task verify` can be exercised locally after `rsync`-ing only `tlpkg/` into
  `staging/tlpkg/`.
- `publish` needs R2 credentials in `RCLONE_CONFIG_R2_*` env vars; there is no mock.
